# passed-in

Run `node scripts/auction.mjs passed-in --json`. For each lot show the sale, the reserve, the best absentee bid and the days since. Suggest re-offering (`/catalogue`) with a revised reserve, selling after the sale at the reserve, or returning it (`node scripts/auction.mjs return <lot>`). Offer `/draft-vendor-report` for the vendor.
