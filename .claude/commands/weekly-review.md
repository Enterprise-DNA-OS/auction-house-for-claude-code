# weekly-review

Run `node scripts/auction.mjs weekly-review --json`. Write it in this order: what needs attention (from `/attention`), the next sale and how many lots and bids it has, how the last sales went, buyers overdue, vendor settlements to pay. Short, numbers in tables.
